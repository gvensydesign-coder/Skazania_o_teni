# Лес по видимости дымки

Дальние холмы, их модели и 88 декоративных деревьев удалены. Земля больше не поднимается у края карты; плавный микрорельеф и русла воды сохранены.

Основной лес хранит компактный каталог постоянных координат. Деревья группируются по пространственным участкам; экземпляры, буферы матриц, объекты выбора и локальные препятствия создаются только для участков, которые могут быть видны сквозь дымку. Общие модели, текстуры и LOD сохраняются в одном наборе, а не загружаются повторно для каждого дерева.

Оценка видимости учитывает основную дымку, дальний горизонт, карту расчистки и запас на крону. Изменение расчистки, режима освещения, густоты дымки или загрузка сохранения обновляет участки. Неизменившиеся участки переиспользуются. При выгрузке освобождаются экземпляры и объекты выбора; общая геометрия и текстуры остаются доступными для следующей подгрузки. Ключи срубленных деревьев стабильны, поэтому новые экземпляры их не восстанавливают.

Проверки: в синтетическом каталоге 1848 деревьев при густоте 1.2 создаётся 600, остальные остаются только координатами. Это результат тестового расположения, не измерение FPS или точное количество деревьев в игровой сцене. Проверены раскрытие дальней зоны, повторное обновление без новых выделений, срубленное дерево, изменение дымки, выгрузка и освобождение буферов. Прежние проверки леса, боя, навигации, сохранений и адаптации проходят. Визуальный прогон в браузере недоступен в этой среде.
