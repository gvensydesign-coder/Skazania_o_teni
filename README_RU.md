# Сказание о Тени — полный переносимый проект, версия 184

Начните с этой инструкции. Рабочая игра находится в `dist/`; это готовый статический веб-проект. Сборка npm, база данных и API-ключи для его запуска не нужны. Все игровые модели, изображения, звуки, текстуры, иконки и используемый Three.js поставляются локально.

## Запуск на компьютере

Установите Python 3, откройте терминал в распакованной папке и выполните:

```
python tools/serve.py
```

Откройте `http://localhost:8000`. На Windows можно запустить `START_WINDOWS.bat`. Не открывайте `dist/index.html` двойным щелчком: загрузка моделей, текстур и звуков требует HTTP-сервера.

## Перенос на сервер

1. Загрузите **содержимое** `dist/` в корень сайта. Сохраните регистр имён и вложенные папки.
2. Используйте HTTP/HTTPS и корректные MIME-типы. Инструкции и готовые настройки находятся в `deployment/README.md`.
3. После загрузки проверьте меню, новеллу, материалы деревни, звук, стройку, сохранения и три ночи. Шейдеры зависят от браузера и видеокарты: они требуют визуальной проверки на целевых устройствах.
4. При смене адреса сайта прогресс из старого браузерного хранилища автоматически не переносится. Перед переездом выполните `tools/EXPORT-SAVE.js` в консоли старой игры, затем `tools/IMPORT-SAVE.js` в консоли новой. Проект не содержит ваших личных сохранений — доступа к браузерному хранилищу пользователя при экспорте не было.

Исходный `.openai/hosting.json` оставлен как сведения о прежнем размещении. Ваш новый сервер его не использует; не публикуйте целиком папку проекта с документацией и `history.bundle`.

## Продолжение разработки

Передайте новому сеансу этот архив и попросите прочитать `handoff/AGENT-START.md`, `handoff/PROJECT-KNOWLEDGE.md`, `handoff/KNOWN-LIMITATIONS.md` и исходные документы. Лучше подключить собственный Git-репозиторий, куда импортирован проект. Учётные данные нового сервера выдаются отдельно, их нет в архиве.

Исходники игры одновременно являются файлами в `dist/`: минификация или отдельная скрытая сборка не используется. `tests/` содержит проверки, `tools/` — инструменты, `docs/` и `reports/` — решения и аудит, дизайн система находится в `dist/design-system.css`, `dist/responsive.css`, `dist/style.css`, `dist/DESIGN-SYSTEM-RULES.md` и связанных документах. Шейдеры встроены в JS-файлы; указатель расположен в `handoff/SHADERS.md`.

`history.bundle` находится только в отдельном полном архиве `Skazanie-o-Teni-v184-full.zip`, сохранённом в ChatGPT. В GitHub загружена актуальная игра и документация; bundle истории (251 МиБ) превышает лимит обычного файла GitHub. В полном архиве он содержит доступную полную Git-историю, включая старые версии. Для восстановления выполните:

```
git clone history.bundle restored-project
```

После клонирования прочтите `handoff/VERSION.json` и проверьте соответствие HEAD указанному коммиту. Исторические версии могут содержать старые и неиспользуемые ассеты; запускать следует актуальную папку `dist/` этого экспорта. Три старых пакета публикаций не дублируются в корне экспорта, но присутствуют в истории, где они были отслеживаемыми файлами.

## Проверка комплектности

```
python tools/verify_package.py
```

Файл `MANIFEST-SHA256.json` перечисляет размеры и контрольные суммы. `handoff/VALIDATION.json` содержит результат проверки ассетов. Проверки логики запускаются через `node tools/run-tests.cjs` при установленном Node.js; Node.js требуется для разработки и тестов, а не для работы игры на статическом сервере.

Это экспорт опубликованной версии 184 с дополнительными инструкциями для переноса и исправленными ресурсами: обрезанный low-normal.png пересоздан из целого исходного атласа low.glb. Геометрия, UV и цветная текстура не менялись; подробности в handoff/ASSET-REPAIR.json. Повреждённый звуковой дубликат fire-new.ogg восстановлен из целого fire-new.mp3; оригинальный MP3 сохранён. Исторический Git bundle сохраняет исходную опубликованную версию. Успешные автоматические проверки не означают доказанное отсутствие всех ошибок: ограничения указаны явно в `handoff/KNOWN-LIMITATIONS.md`.
